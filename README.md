# Instagram HD Downloader

موقع بسيط لتنزيل فيديوهات Instagram بأعلى جودة متاحة.

## مهم
GitHub Pages وحده لا يستطيع تنزيل فيديوهات Instagram لأن العملية تحتاج Backend.
هذا المشروع مجهز بواجهة أمامية + API endpoint، ويمكن نشره بسهولة على Vercel.

## التشغيل على Vercel
1. ارفع الملفات إلى GitHub.
2. افتح Vercel وسجّل الدخول بحساب GitHub.
3. اختر هذا المستودع ثم Deploy.
4. الموقع سيعمل على رابط Vercel.

## ملاحظات
- يدعم روابط Instagram العامة التي يستطيع محرك التنزيل الوصول إليها.
- لا يمكن رفع الجودة فوق جودة الفيديو الأصلي.
- لا تستخدمه لتنزيل محتوى لا تملك حق تنزيله.
