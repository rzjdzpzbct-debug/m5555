موقع سكينة — ملفات جاهزة

الملفات:
- index.html: واجهة الموقع
- style.css: التصميم والخلفية
- script.js: قائمة التلاوات وروابط YouTube
- background.jpg: ضع هنا صورة الخلفية الثلجية التي أرسلتها، وسمّها background.jpg

طريقة النشر على GitHub Pages من الآيفون:
1) فك ضغط الملف.
2) ارفع الملفات الأربعة إلى مستودع GitHub نفسه (index.html و style.css و script.js و background.jpg).
3) اجعل المستودع Public إذا كنت تستخدم GitHub Pages المجاني.
4) Settings > Pages.
5) ضمن Build and deployment اختر Deploy from a branch، ثم main و /(root)، واضغط Save.
6) انتظر قليلاً وافتح الرابط الذي يظهر في صفحة Pages. عادةً يكون:
   https://USERNAME.github.io/REPOSITORY/
   استبدل USERNAME و REPOSITORY باسم حسابك واسم المستودع.

مهم:
- أضفت رابطَي YouTube اللذين أرسلتهما.
- لا يمكن ضمان تشغيل الصوت تلقائياً على iPhone؛ iOS وYouTube قد يتطلبان ضغطة تشغيل.
- مشغّل YouTube المضمّن يعرض الفيديو أيضاً، لأن تضمين الصوت فقط من رابط فيديو YouTube ليس مضموناً/مدعوماً كملف صوت مستقل.
- لا تضع كلمات مرور أو رموز دخول داخل ملفات الموقع.
